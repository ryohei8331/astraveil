# ASTRAVEIL（アストラヴェイル）ゲームデザイン文書

「MMO風」シングルプレイ・アクションRPG。ブラウザ(PC/スマホ)で動作。
架空の超大作VRMMOを一人で遊んでいる、という体裁のメタフィクション演出を全面に敷く。

## 世界観

**星鋼紀(せいこうき)** と呼ばれる高度SF文明が崩壊してから千年後のファンタジー世界。
プレイヤーは「開拓者」として未踏域を広げ、星鋼紀の遺物と世界の真相に迫る。
ゲーム内では本作は総プレイヤー数2,800万人の伝説的VRMMO「ASTRAVEIL ONLINE」であり、
グローバルチャット・クラン・パッチノート・他プレイヤーの雑踏がすべて演出として流れる。

## 基本ステータス(仕様書準拠)

| 略号 | 名称 | 効果 |
|---|---|---|
| HP | 体力 | 0で戦闘不能 |
| MP | 魔力 | 魔法消費。**残量比率で威力が変動**(枯渇時威力低下) |
| STM | スタミナ | 行動で消費。低下すると移動・攻撃速度が鈍化 |
| STR | 筋力 | 物理攻撃力・重量武器の装備制限 |
| DEX | 器用 | 急所(背面)命中率・クリティカル倍率 |
| AGI | 敏捷 | 移動速度・回避無敵フレーム数 |
| TEC | 技量 | 武器習熟の立ち上がり速度・スキル最大習得数 |
| VIT | 耐久 | 防御。低いと防具越しに**透過ダメージ**を受ける |
| LUC | 幸運 | クリ率・ドロップ率補正 |
| 満腹度 | Hunger | 時間で低下。一定以下でSTM自然回復が停止 |

### 落下ダメージ(仕様書の式をそのまま実装)
D = max(0, α·(h − h0))。空蹴りで分割時:
D_total = max(0, α·(h1 − h0)) + max(0, α·(h2 − h0))

## 魔法
コマンド詠唱ではなく**呼吸同調チャージ**: ボタン長押しで体内循環(リングが収縮)、
好機で離すと出力上昇(タイミングボーナス)。威力はMP残量比率でスケール。
四元素(火/水/風/土)+雷。**雷のみ指向性分岐**: 短押し=前方放射、満タメ=天空からの落雷(AoE)。

## ver 3.0 拡張システム

### HD-3D描画(renderer3d.js)
素のWebGL。タイルをボクセル押し出し(壁・樹・門は立体、水は半透明面、奈落は深淵)、
キャラ/FX/UIは既存2D描画を透視投影位置に奥行きソートで重ねる方式。
フォグ・昼夜の色調・深海の青被りはシェーダuniform。2D/3Dはシステムメニューで切替。

### 行動成長(growth.js)
13種の行動カウンタ(回避/被弾/詠唱/歩行/夜歩き/食事/跳躍/落下/発掘…)が閾値を跨ぐたび
対応ステータス+1(1ステ上限+25)。「やったことが人格になる」成長。

### 固有スキル生成(skillforge.js)
行動カウンタが生成閾値に達すると、テンプレート×現在ステータス×乱数でパラメータと
**名前**(形態素合成: 宵/朧/餓…×閃/駆/纏…)を鋳造し、固有スキルとして付与。
種族30体討伐で特効スキル、属性60回詠唱で深奥スキルなど。セーブに保存されロードで再登録。
固有スキルは修得上限の対象外。

### 社会システム(social.js)
- 好感度: 会話(日次)/購入/宿泊で上昇。tier3段階で台詞・割引(最大15%)・♥表示が変化
- 名声: クエスト/ボス/世界フラグで上昇、死亡で微減。4段階の称号。偽チャットに本人の噂が流れる
- 悪名: 月兎を殺すと消えない記録が残る
- クラン: 6クランに加入条件+特典。加入後はクラン内会話がチャットに混ざる

## 技術方針
- 素のJS(script tagグローバル名前空間 `G`)。file://直開きでも動作
- Canvas 2D、固定タイムステップ60Hz、描画はrAF
- グラフィックは全て手続き生成(外部アセット無し)、音はWebAudio合成
- セーブ: localStorage自動+手動スロット+JSONエクスポート/インポート
- データ駆動: `js/data/*.js` が `G.DATA.*` レジストリに登録するだけで拡張可能
