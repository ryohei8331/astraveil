# ASTRAVEIL（アストラヴェイル）

架空の超大作VRMMO「ASTRAVEIL ONLINE」を一人で遊ぶ、という体裁の
ブラウザ製オープンワールド風アクションRPG。PC・スマホ両対応。

> 星鋼紀と呼ばれるSF文明が崩壊してから千年。あなたは開拓者として
> 未踏域を切り開き、隠された世界設定と「七凶星」の謎に迫る。

## 遊び方

### いちばん簡単(PC)
`index.html` をブラウザで開くだけ(ダブルクリック)。

### スマホで遊ぶ / 推奨
`start.command` をダブルクリック → 表示されたURLをPCまたはスマホで開く
(同一Wi-Fi内なら `http://<MacのIP>:8765` でスマホから遊べます)。

## 操作

| 操作 | PC | スマホ |
|---|---|---|
| 移動 | WASD / 矢印 | 左バーチャルスティック |
| 攻撃 | J / クリック | ⚔ボタン |
| 回避 | K / Shift | 💨ボタン |
| スキル | 1〜4 | スキルボタン |
| 魔法(長押しチャージ→好機で離す) | L | ✨ボタン長押し |
| 魔法属性の切替 | U | 属性玉をタップ |
| 調べる/話す | E / Space | 🔍ボタン |
| SOS救難信号(HP20%以下) | H | SOSボタン |
| メニュー | M / Esc | ☰ボタン |

## 攻略のヒント(ネタバレ薄め)
- 満腹度が20を切るとスタミナが回復しなくなる。パンは多めに
- 「クエストマーカーが出ない物語」がいくつも埋まっている。看板・掲示板・酔っ払いの噂話は全部ヒント
- 月齢は8日周期。**満月の夜**にしか起きないことがある
- 武器を外すという選択肢が意味を持つ場所がある
- 夜、3のつく日に平原へ出るのはやめておけ(フラグ)

## 開発者向け
- ヘッドレスE2Eテスト: `node tests/smoke.js`(ブラウザ不要で全システムを通し検証)
- データ駆動設計: `js/data/*.js` にファイルを足すだけでゾーン・敵・アイテム・クエストを拡張可能

## セーブ
自動保存(localStorage)。メニューからスロット保存・JSON書き出し/読み込みが可能。
